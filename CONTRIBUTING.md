# Contributing to Noctaxis

Bug fixes, translations, documentation improvements and feature ideas are welcome. I'm developing Noctaxis independently, so please check the existing issues before spending time on a large change.

If you're submitting a pull request, keep it focused, describe what changed, and run the relevant tests where practical. Please only submit code, images or other material you're allowed to contribute.

For new languages or translation corrections, follow the [Contributing Translations guide](https://github.com/CallyyllaC/Noctaxis/wiki/Contributing-Translations).
