# Installing Noctaxis

Noctaxis is currently distributed as a portable application. There's no installer yet, but you can download and run the application directly.

## Download

Get the latest available build from [GitHub Releases](https://github.com/CallyyllaC/Noctaxis/releases).

Windows x64 is the only officially supported platform. Windows ARM64, Linux and macOS builds are provided on a best-effort basis and haven't been tested on physical hardware.

## Getting started

1. Download the package for your operating system.
2. Extract it to a folder of your choice.
3. Run the Noctaxis application from the extracted folder.

Noctaxis isn't currently code-signed, so your operating system may display a security warning. Only run software you've downloaded from a source you trust.

## Future installers

I'm planning to provide proper installers in a future release. Until then, Noctaxis remains a portable download.
