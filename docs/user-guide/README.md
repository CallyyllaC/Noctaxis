# Noctaxis
**Plan for the sky. Frame for the shot.**

Noctaxis is a desktop planning application for photography and astrophotography.
Explore locations, plan around celestial events, preview camera compositions, and examine terrain, weather and light pollution before heading out.
New to Noctaxis? Start with Getting Started, or explore the Planner documentation.

- [About](about.md) — Learn more about Noctaxis and its purpose.
- [Getting Started](getting-started.md) — Create your first photography plan.

## Documentation

- [Locations](locations.md) — Find, save and manage your favourite locations.
- [Planner](planner.md) — Plan your shots, explore the sky and assess conditions.
- [Settings](settings.md) — Customise Noctaxis, manage equipment and adjust your preferences.
