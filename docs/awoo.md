## Overview

I've used a lot of online photography and astronomy planning tools over the years. Some are badly made, some are good but limited in scope, many are mobile-only, and far too many come with unpleasant subscription models.

Noctaxis is my attempt to build the one I would actually want to use: useful, convenient, and somewhere between feature-rich and needlessly complicated.

It is still in active development, but I'm happy with where it is going. It looks modern and, somewhat suspiciously, like it was made by a professional. I am not one.

The plan is to reach a solid V1 around the features below. After that, development will mostly follow my own use cases, along with user feedback that seems useful, sensible, and realistically achievable.

## Key features

- Completely free, with no paid feature gates, required accounts, subscriptions, or user-supplied API tokens
- Celestial object tracking
- Customisable camera and lens framing
- Terrain-aware planning
- Weather view
- Date and time configuration
- Global location support
