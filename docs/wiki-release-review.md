Regression tests cover a control bound before startup and invalid required fields without saving those edits. The capture host no longer edits a profile to clear the warning. - **Screenshots:** only successful native captures or production-exporter images may be inserted. Pending image markers are invisible Markdown comments, not claims that an image has been captured. Review capture reports and images before publishing.
